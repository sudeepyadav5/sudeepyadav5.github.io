# Sudeep Yadav Portfolio

Static portfolio website for Sudeep Yadav, organized for GitHub Pages hosting.

## Project Structure

```text
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── google-apps-script/
│   └── contact-form.gs
├── GOOGLE_APPS_SCRIPT_SETUP.md
└── assets/
    ├── documents/
    └── images/
        ├── backgrounds/
        ├── profile/
        └── projects/
```

Downloadable CV and cover-letter files are stored in `assets/documents/`.
Open `index.html` directly or publish the repository with GitHub Pages.
